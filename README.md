# رحلة الأبطال الصغار في محطّات الصحّة — الوسائط الرقمية

صفحة تفاعلية عربية ترافق خطّة نشاط بدني بإستراتيجية المحطّات لطلبة الصف الأول الابتدائي (6–7 سنوات).

**افتح الصفحة:** https://htmlpreview.github.io/?https://github.com/alozy666/little-heroes-stations/blob/main/index.html

(الرابط البديل عند عمل GitHub Pages: https://alozy666.github.io/little-heroes-stations/)

| القسم | الاستخدام | رابط مباشر |
|---|---|---|
| مؤقّت المحطّات | للمعلّمة على شاشة الصف: 5 دقائق لكل محطّة، وجدول دوران الفرق الخمس، وموسيقى الانتقال | `#timer` |
| بطاقات المحطّات | تعليمات مصوّرة لكل محطّة بمستويين وتنبيه سلامة | `#station-1` … `#station-5` |
| لعبة سلّة الطعام | نسخة رقمية من المحطّة 3: صحّي أم غير صحّي؟ | `#food` |
| حديقة الحيوانات | سحب بطاقة حيوان عشوائية وتقليد حركته | `#animals` |
| قصّة النشاط | عرض مصوّر لخطوات الحصّة (بدل الفيديو) | `#story` |
| كيف كانت رحلتي؟ | تقويم ذاتي بالوجوه التعبيرية | `#me` |
| تحدّي الأبطال الأسري | محطّتان في البيت كل أسبوع ولوحة نجوم | `#family` |

- صفحة واحدة (`index.html`) بلا مكتبات JavaScript خارجية (الخطوط من Google Fonts)، تعمل على الحاسوب والشاشة الذكية والهاتف.
- لا تجمع أي بيانات ولا تطلب تسجيلًا؛ ما يختاره الطفل يُحفظ على جهازه فقط (localStorage).
- الرسوم التوضيحية مولّدة بالذكاء الاصطناعي ولا تمثّل أطفالًا حقيقيين.

مقرّر TCHL418 — المشروع 3.
